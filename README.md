# Python_Numpy_Pandas_Seaborn_Matplotlib 🚀

A structured repository containing practical code, notebooks, and reference materials for mastering core Python data science libraries: **NumPy**, **Pandas**, **Matplotlib**, and **Seaborn**.

---

## 📌 Repository Overview

This repository acts as a hands-on guide for data manipulation, numerical computing, and data visualization. All core topics are organized into dedicated Jupyter Notebooks for ease of navigation and testing.

---

## 🛠️ Included Topics & Modules

* **NumPy (`numpy.ipynb`)**
  * N-dimensional array initialization and shape manipulation
  * Vectorized operations, broadcasting, and universal functions (ufuncs)
  * Indexing, slicing, boolean masking, and random sampling

* **Pandas (Upcoming)**
  * DataFrames & Series creation and handling
  * Data cleaning, missing value strategies, and type casting
  * Grouping (`groupby`), aggregation, merging, and pivot tables

* **Matplotlib (Upcoming)**
  * Basic plotting: line, scatter, bar, and histograms
  * Customizing figures, axes, legends, and styling

* **Seaborn (Upcoming)**
  * Statistical graphics: distribution plots, boxplots, heatmaps, and pairplots
  * Theme and color palette customization

## ⚡ Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/sonjor46/Python_Numpy_Pandas_Seaborn_Matplotlib.git
cd Python_Numpy_Pandas_Seaborn_Matplotlib
```

### 2. Install Required Dependencies
```bash
pip install numpy pandas matplotlib seaborn jupyterlab
```

### 3. Launch Jupyter
```bash
jupyter lab
```
