# Python Data Science Toolkit 🚀

A comprehensive collection of practical code, tutorials, and projects covering the core libraries of the Python data science stack: **NumPy**, **Pandas**, **Matplotlib**, and **Seaborn**.

---

## 📌 Repository Overview

This repository serves as a hands-on guide and reference manual for data analysis and visualization in Python. Whether you are manipulating large datasets, performing linear algebra, or creating publication-ready statistical plots, you will find modular, easy-to-follow Jupyter Notebooks and scripts here.

---

## 🛠️ Tech Stack & Key Topics

* **NumPy (`/01_numpy`)**
  * N-dimensional array creation, slicing, and reshaping
  * Vectorized operations and broadcasting
  * Linear algebra, random sampling, and mathematical routines

* **Pandas (`/02_pandas`)**
  * Series and DataFrames operations
  * Data cleaning: missing value handling, duplicate removal, type casting
  * Grouping (`groupby`), merging, joining, and pivot tables
  * Time-series processing and file I/O (CSV, Excel, JSON)

* **Matplotlib (`/03_matplotlib`)**
  * Object-oriented plotting fundamentals
  * Line plots, scatter plots, bar charts, and histograms
  * Customizing axes, labels, legends, colors, and layouts
  * Exporting high-resolution figures

* **Seaborn (`/04_seaborn`)**
  * High-level statistical visualization
  * Distribution plots (KDE, boxplots, violin plots)
  * Categorical plots, regression plots, and heatmaps
  * Customizing themes, palettes, and pair grids

## ⚡ Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/Python_Numpy_Pandas_Seaborn_Matplotlib.git
cd Python_Numpy_Pandas_Seaborn_Matplotlib
```

### 2. Set Up a Virtual Environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Launch Jupyter Lab
```bash
jupyter lab
```
